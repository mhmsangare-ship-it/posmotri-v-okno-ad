# Посмотри в окно

Проектная работа Яндекс Практикума: стилизация готового приложения, которое показывает видео из окон разных городов, со списком карточек и формой поиска по городу и времени суток.

Репозиторий проекта: https://github.com/mhmsangare-ship-it/posmotri-v-okno-ad

## Структура проекта

- `index.html` — разметка страницы и шаблоны (`<template>`) карточки, прелоадера, кнопки «Показать ещё» и блока ошибки
- `styles/style.css` — стили проекта: лейаут на Flexbox, карточки, форма, кнопки и их состояния
- `styles/preloader.css` — стили прелоадера
- `styles/error.css` — стили блока с ошибкой
- `scripts/script.js` — логика приложения: загрузка видео из API, переключение роликов, поиск, подгрузка карточек
- `fonts/` — шрифты Oswald и Fira Sans Condensed и файл подключения `fonts.css`

## Что сделано

- Лейаут страницы на Flexbox по макету
- Кастомные чекбоксы на псевдоэлементе `::after` и псевдоклассе `:checked`
- Состояния `:hover`, `:active` и `:focus-visible` для кнопок, карточек и полей формы
- Обрезка длинного текста: многоточие у заголовков и `line-clamp` у описаний карточек
- Позиционирование прелоадеров внутри блоков с видео и карточками

## Запуск

Откройте файл `index.html` в браузере (лучше через Live Server в VS Code): видео подгружаются из API Практикума.
